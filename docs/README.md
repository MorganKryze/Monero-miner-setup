# The docs

Read this when you open the `docs/` folder and want the page that answers your question. Each page covers one topic, in the order most readers need them.

- [Boards](boards.md): how do I set up a Raspberry Pi 5 or an RK3588 board that mines on first boot?
- [Native install](native-install.md): how do I install and tune the miner on Debian, Ubuntu or macOS?
- [Docker](docker.md): how do I run the miner in a container, with or without the VPN sidecar?
- [Security and privacy](security.md): who sees my mining, what does the project fetch, and what runs as root?
- [Does it pay?](earnings.md): what will I earn, and what does the power cost?
- [Run and watch the miner](operating.md): how do I start, stop, check, update or remove it?
- [Upgrading](upgrading.md): what do I do to update an install made with an earlier release?
- [Troubleshooting](troubleshooting.md): why did the miner or its setup stop, or why does it mine slowly?
- [Development](development.md): what does CI run, and how do I send a pull request?
